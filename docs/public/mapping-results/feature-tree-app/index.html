CI checklist

Get the tests running in CI:

  1. No CI configuration found. Add the headless gate job (docs/guide/ci.md, section 'GitHub Actions — headless gate (with coverage)').
  2. 3 features have pure-function nodes: run the fast gate (npx brighttest --no-sgnode --junit reports/unit.xml) on every push.
  3. 25 headless-testable nodes: run the headless gate (npx brighttest --coverage --lcov coverage/lcov.info --junit reports/junit.xml).
  4. 1 of 5 features have a device or e2e node: add the nightly device job only when you have a self-hosted runner on the device network.
  5. 1 nodes not classified: classify first. No CI job is suggested for them until the agent or a human gives them a class.
  6. This report does not generate workflow files: copy the templates from the CI guide so there is one source.

What cannot be known without a device

Static analysis predicts the lane of each node. These need a device to confirm:

  • instrumentation: 1 node with a device-only aspect
  • playback: 1 node with a device-only aspect
  • task-timing: 1 node with a device-only aspect
  • wall-clock: 3 nodes with a device-only aspect
  • bsc plugins that generate code are not run; generated functions and components are not in the graph
  • ropm prefix rewriting is not modelled; renamed library components appear as unresolved names
  • component names built at runtime from strings are only reported as dynamic
  • functions passed as strings to observeField in other components are not followed
  • Real wall-clock timing, rendering, key handling and platform behaviour that the headless engine does not emulate.

Method and provenance

Rules: the graph, the edges, the call confidence and each node's predicted class come from a deterministic analysis of the project files (rule ids are in the member tables). Agent judgement: the grouping into features, the names and summaries, the risk, the proposed tests and any class override are written by brighttest and validated against the graph. Feature dependencies are computed from graph edges and are never authored.
